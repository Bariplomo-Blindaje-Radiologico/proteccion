# BARIPLOMO — Blindaje Radiológico

Versión corregida para Vite + React.

## Correcciones incluidas
- `index.html` apunta correctamente al punto de entrada React.
- Corregido el punto de entrada que provocaba el fallo de Vercel.
- Eliminado el `tailwind-config.js` externo que provocaba el fallo de compilación.
- Estructura Vite/React completa con `package.json`, `vite.config.js` y `vercel.json`.
- Un único menú principal en React.
- MATERIALES: Barita, Mortero, Hoja/Lámina/Placa de Plomo y Pegamento.
- PRODUCTOS: Vidrio, Puerta y Mampara.
- ESTUDIOS CERTIFICADOS: Memoria y Levantamiento.
- SERVICIOS: Aplicación y Colocación.
- Se conservan las páginas y fichas técnicas del paquete recibido.

## Publicación
1. Sustituir el contenido del repositorio por el contenido de este paquete.
2. Hacer commit en la rama `main`.
3. Vercel ejecutará `npm run build` y publicará `dist`.
